# Brother's Gym 🏋️‍♂️  
A complete fitness gym website built using **HTML, CSS, JavaScript, Bootstrap, PHP & MySQL**.

This project is designed for a local gym where users can view services, membership plans, trainers, gallery, and contact details.  
The backend handles form submissions, user registration, login, and database storage.

---

## 🚀 Features
- Modern & responsive UI using **Bootstrap**
- Dynamic pages powered by **PHP**
- Database integration using **MySQL**
- Membership plans & pricing section
- Trainer profiles & gallery page
- Contact form with backend handling
- Fully mobile-friendly design

---

## 🛠 Tech Stack
**Frontend:**
- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  

**Backend:**
- PHP  
- MySQL Database
